# Replit setup

## Run the app

The project is a Vite + React application. The configured Replit workflow is:

```bash
npm run dev -- --port 5000
```

Open the Replit preview after the `Start application` workflow is running.

## Local commands

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build
- `npm run lint` — run the TypeScript check

No external service or secret is required for the current browser-only experience.
